# Garvin Patel Portfolio

Personal portfolio for [dr-garvin.com](https://dr-garvin.com), hosted with GitHub Pages.

## Preview locally

From this folder, run:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

The site is static, so edits to `index.html` appear after refreshing the browser. Publishing requires an intentional, reviewed commit and push to the `main` branch.
